# SecureCloud Project Brief

## What

SecureCloud is a private cloud-storage web application for keeping an organization's files in one place. Users should be able to organize files and share them with other authorized people.

## Who

- Organization members who store and manage files.
- Administrators who manage users and access.

## Nouns

- User
- File
- Folder
- Share
- Permission
- Storage location

## Verbs

- Register and sign in
- Upload and download files
- Create and organize folders
- Share files
- Grant or remove access
- Delete and restore files

## Current project state

The frontend currently demonstrates login, registration, and a storage dashboard. The backend includes the Assignment 4 File Service API, which stores file metadata in memory, plus a local Identity Service demo for its account-status check. Database-backed storage and the other file-management actions remain planned work.
